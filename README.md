# indicators_trends_and_analysis

## settings
Python


## purpose
the purpose of this repository is to extract, tranform and load data from different sources and make them available for different uses


## data sources
Extracted data 
    - World bank : for countries referential
    - World bank : for macroeconomic et social indicators (+2500 indicator for +200 countries)
    - IRCC : for immigration data to canada
    - different other sources : for specific indicators

manual data 
    - countries continent : assign countries to continent + sub-regions
    - selection indicators : ca be used to filter specific countries
    - selection countries : can be used to filter specific indicators
    - Freedom House Index file : blocked for automatic extraction

Resources output
Data generated by different codes
    - raw from sources
    - transformed and compilied with other data


## outputs
outpus can be final files to be used 
- csv files
- mp4 files (for race bar charts)

outputs can also be files to be used for other analysis 
- csv files
